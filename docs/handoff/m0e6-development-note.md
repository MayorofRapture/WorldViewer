# M0E6 development note

The current M0E5 physical-reference run was collected in a constrained physical space. The operator reported difficulty achieving the full negative-X reference position, and the resulting negative-X measurements were inconsistent. One negative-Y hold also lacked usable facial-transform output. The collection may be used for development/debugging context but must not be treated as final calibration-acceptance evidence. Physical calibration should be recollected or reviewed before M0E8/final production-default selection if calibration accuracy remains material.

This is a deferred validation issue. It does not modify the frozen M0E5 procedure, Class C experiment specification, oracle, thresholds, or evidence acceptance criteria.
