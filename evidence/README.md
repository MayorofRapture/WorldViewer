# Evidence

`evidence/` is the durable, source-controlled home for WorldViewer experiment, hardware/performance, conformance, and acceptance evidence.

Evidence supports verification; it does not replace the specification, contract, ADR, or oracle that defines correctness. Prefer reproducible text, JSON, CSV, and similar formats where practical. Large or unsuitable binary artifacts may be referenced rather than committed.

Create milestone- or subsystem-specific directories only when real evidence work requires them. Do not add placeholder results, empty traces, or invented acceptance claims.
